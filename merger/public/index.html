    📖 توثيق API للمطورين
    الطريقةالمسارالوظيفة
    POST/api/jobsإنشاء مهمة دمج
    POST/api/upload?job=&seq=رفع أجزاء ملف (ثنائي ≤4MB)
    POST/api/jobs/{id}/processتنفيذ الدمج → رابط الفيديو النهائي

    GET/api/configالحدود العامة
    GET/api/cronحذف المنتهية (يومي)
